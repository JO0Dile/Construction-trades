# Accessibility statement

**Trades Work Manager — Israel edition**

Last revised: 6 September 2026. Draft, pending an accessibility audit.

> Israeli accessibility regulations require service providers to publish a
> statement of this kind, and set out what a digital service has to meet. This
> is an honest account of where the app stands, not a claim of compliance.
> What it needs is an audit by somebody qualified, and the gaps below closed.
> See `docs/COMPLIANCE.md`.

## What has been done

**Every language, in the right direction.** Hebrew, Arabic and English, with
right-to-left layout throughout rather than a mirrored afterthought. Numbers,
dates and currency are formatted for the reader's locale. Stored identifiers
are not — a reference number reads the same on every phone, which matters when
it is being matched against paper.

**Text scales.** The interface uses scalable text units, so the system font
size setting works. Layouts wrap rather than truncate where they can.

**Screen readers.** Buttons and images that carry meaning have content
descriptions; images that are decoration are marked as such rather than being
announced. Touch targets follow the platform minimum.

**Colour is not the only signal.** Where a row is coloured — an overdue
payment, a rejected work package, a permit near expiry — the same fact is also
written in words.

**Contrast.** The dark theme is the default and was chosen for a screen read
in daylight on a site. Both themes use the platform's own colour roles.

## What has not been done

* **No audit.** Nothing here has been checked by an accessibility
  professional or against IS 5568 clause by clause.
* **No testing with real users** who use a screen reader, a switch, or
  magnification.
* **Signature capture** requires a drawn signature. There is no alternative
  route for somebody who cannot draw one, and that is a genuine barrier rather
  than an oversight to be argued away.
* **Photographs as evidence** assume sight. A blind user can record everything
  else, but cannot verify what a photograph shows.
* **Contrast has not been measured.** It has been chosen, which is not the
  same thing.

## Reporting a barrier

A firm publishing this app has to name a contact here — a person, an email and
a phone number — and answer within the period the regulations set. That
contact is deliberately left blank rather than invented.
